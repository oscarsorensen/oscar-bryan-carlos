# oscar-bryan-carlos
Un repositorio para nuestro proyecto en entornos de desarrollo
(traker de peliculas)


Este proyecto es un sitio web para el seguimiento de películas, inspirado en plataformas como Letterboxd. El objetivo es permitir a los usuarios llevar un registro de las películas que han visto, las que quieren ver y añadir valoraciones o reseñas. El sitio ofrecerá una interfaz sencilla y clara para gestionar listas de películas y crear un diario personal de cine. El proyecto se desarrolla como un ejercicio de aprendizaje en desarrollo web, centrado en la estructura de una web completa, la interacción con el usuario y la organización de los datos de forma clara y escalable.
